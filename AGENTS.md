# Project intent

Build a reusable probabilistic fundamental forecasting and valuation system, starting with Nestlé. Python performs calculations; Excel provides an inspectable review interface. The package contains a generic AI-driven historical initiation workflow using local company originals and vendor exports, with ten years by default; the obsolete synthetic FX demonstration and setup configs have been removed. API/model/effort settings load from private local `.env` or environment variables; live company-initiation accuracy has not been verified. The construction milestone adds driver interfaces, executable temporary forecasts and an inspectable Excel model. The 23 October extension makes Assumptions authoritative and adds reusable fiscal periods, reporting bridges and supplied FX data. DCF and probabilistic driver forecasting remain deferred.
